# Vermillion

Instant-replay game clipping for Windows. No watermark, no account, nothing extra in your clips.

## Download

Get **`VermillionSetup-<version>.exe`** from the [latest release](https://github.com/veraci-ty/vermillion-releases/releases/latest) and run it.

Windows will probably say **"Windows protected your PC"** because the installer isn't code-signed. Click **More info → Run anyway**.

Once installed, Vermillion updates itself: it checks for new versions every few hours and installs them while you're not in a game. Settings → General → Updates shows your version and has a **Check now** button.

## Keys

| Key | What it does |
|---|---|
| **Alt+V** | Open or close the overlay |
| **Alt+C** | Save the last 30 seconds |
| **Alt+Shift+C** | Save the last 2 minutes |

All of them can be changed in Settings → Hotkeys.
